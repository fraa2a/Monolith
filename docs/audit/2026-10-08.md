# Monolith repository audit - 2026-10-08

This report accompanies three English pull requests. The baseline is `db3056f5` on `main`. The packaging branch is the base of the technical audit; the comment branch is based on the technical audit. Review and merge in that order so the diffs stay separate.

## Scope and evidence

The review covers the recorder, native libraries, both Tauri hosts and frontends, Stream Deck plugin, updater, build/release/installer configuration, tests and repository documentation. [The file inventory](file-inventory.md) accounts for every tracked file and new deliverable, including generated schemas, lockfiles and binary assets. Generated files and assets receive configuration/metadata review rather than independent source-code verification. Static review, portable regression tests and cross-compilation checks have different limits. No claim of defect-free code, measured production speedup, clean Windows installation or hardware-capture runtime validation is made.

Historical findings in `report.md` and `research_codebase/` remain historical records. This report does not mark their entire backlog resolved.

## PR 3: startup DLL failure and other release fixes

The app-local dependency closure must include DLLs imported by DLLs, not only those imported directly by the EXE. The native recorder retains dynamic MSVC linkage and CMake stages the redistributable runtime next to it. Rust UI/updater use static CRT linkage so independent single-executable component packages have matching runtime contracts.

The recursive verifier checks imports relative to each executable's own directory and refuses to count Visual Studio/VC runtime DLLs installed on a CI runner as operating-system prerequisites. It runs on the release folder and engine/UI/updater component staging before packaging. Eight verifier regressions include missing nested dependencies and sibling-directory masking.

Additional release findings: the pinned x264 GitLab archive failed its SHA512 check, so an overlay fetches the same upstream commit through Git; overlay registration uses `vcpkg-configuration.json`. The updater Cargo version now agrees with its Tauri 1.0.1 version. Desktop fullscreen has the explicit maximize/unmaximize capabilities it calls. The repository text policy rejects the two prohibited long-dash code points, including in CI.

This corrects the packaging contract for the reported startup failure. It does not prove the specific installed build launches on a clean Windows 11 machine. Drivers, dynamically loaded libraries and WebView2 require that smoke test.
