# Audit corrections

Baseline: `2e8c4ec1616215344b968a5f09a004cf9df6d494`. PR: https://github.com/fraa2a/Monolith/pull/8.

This is the implementation record for the user-approved audit. Each finding has a concrete correction or an explicitly bounded mitigation. Final verification is recorded in the PR and active handover. Portable tests and browser fixtures do not certify Windows hardware, WebView2 playback, clean installation or power-loss durability.

Both frontends run TypeScript and Vite checks. Chromium executes the desktop layout/interaction and audit fixtures. Stream Deck uses its production build and real socket tests. PowerShell produces a signed release fixture consumed by Rust with a test key. Windows CI additionally exercises real process exit, running-image replacement, recovery launch and native compilation.

Before release, execute real WGC target switching, audio/device recovery, long-session synchronization, slow-disk shutdown, WebView2 range/multitrack playback, close/save failure handling and a clean-VM install/update smoke test. Journal recovery does not establish certified power-loss durability.
